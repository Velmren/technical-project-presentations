# Project structure

LACUNA, an orbital salvage game interface. Plain ES modules and CSS, no build step; Three.js is vendored.

```
game-concept/
├── index.html              Document shell: icon sprite, top bar, screen sections, dialogs, import map
├── serve.mjs               Local static server (127.0.0.1:4353)
├── package.json            Script shortcuts (start, check, verify, record, build, vendor)
├── metadata.json           Title, version, screens and runtime summary for the portfolio
├── thumbnail.webp          Catalogue thumbnail, captured by tools/verify.mjs
├── README.md               How to run and what to try
├── DESIGN.md               Premise, loop, interface rules, visual system, 3D approach, references
├── ASSETS.md               Procedural content, fonts and code licences
├── PROJECT_STRUCTURE.md    This map
├── assets/
│   └── fonts/              Tektur (display) and Lacuna Text (IBM Plex Sans, renamed) subsets with OFL texts
├── src/
│   ├── main.js             Routing, rendering from state, actions, keyboard, dialogs, stage bridge
│   ├── state.js            Persistent game state and preferences (localStorage, v4 migration)
│   ├── game.js             Game actions: accept, fit, service, launch, decide, settle, trade, reply
│   ├── rules.js            Pure rules: power, mass, fuel, hold space, readiness, operation settlement
│   ├── audio.js            Optional synthesised interface sounds and ambience (Web Audio)
│   ├── i18n.js             Dictionary lookup, interpolation, locale number and clock formatting
│   ├── data/               equipment.js, contracts.js, operations.js (steps and options),
│   │                       items.js (salvage), comms.js (client messages and reply effects)
│   ├── locales/            en.js and ru.js with every interface string
│   ├── screens/            One module per screen: intro (title screen), sector, dock, bench, operation,
│   │                       results, hold, log, comms, settings; guide.js: buyout meter, "Now" line and
│   │                       first-job hints; shared.js: checklists, chips and thumbnails
│   ├── ui/                 art.js (icons, module drawings), dialogs.js (confirmation)
│   └── render/
│       ├── stage.js        Renderer, three worlds, cameras and framing, post-processing, quality tiers
│       ├── kit.js          Hard-surface modelling kit: fillets, lofts, lathes, extrusions, batching
│       ├── materials.js    Procedural PBR library with wear shader, decals and stencils
│       ├── vessel.js       MULE–06
│       ├── tools.js        KESTREL C–8, LATCH G–2, HELIOS A–9
│       ├── hangar.js       Service bay, lights, light probe, inspection table, lift shaft, doors and carriage
│       ├── sector.js       Gas giant, ring, debris, markers and route for the sector map
│       ├── operation.js    Operation vignette: wrecks, debris field, vessel poses, flight and step timelines
│       ├── exhaust.js      Engine plumes and reaction-control jets for the vessel in flight
│       └── items.js        Salvage item models, rendered once into hold thumbnails
├── styles/
│   ├── base.css            Fonts, tokens, type roles, buttons, chips, motion
│   ├── shell.css           Stage, top bar, navigation, 3D-anchored overlays, toast, dialogs
│   ├── screens.css         Sector, drydock and bench layouts; medium and phone rules
│   └── pages.css           Operation, results, hold, log, comms and settings; phone sheets
├── tools/
│   ├── verify.mjs          End-to-end checks of the whole loop, screenshots, renderer figures, thumbnail
│   ├── record.mjs          Real browser recording of the whole loop (desktop or phone), with a dry run
│   ├── build.mjs           Copies the runtime to ../../public/projects/game-concept/
│   ├── vendor-three.mjs    Refreshes vendor/three from the portfolio's node_modules
│   ├── check-syntax.mjs    Parses every module with Node
│   ├── check-paths.mjs     Plays every operation option path of every contract through the game rules
│   ├── audit-geometry.mjs  Open meshes, cables through parts, floating parts, modules seated on the table
│   └── lib/
│       ├── browser.mjs         Shared Playwright launch (GPU or software WebGL), local server, readiness
│       └── geometry-audit.js   Browser side of the geometry audit (records every assembled part)
└── vendor/
    └── three/              Three.js 0.180.0 runtime and the example modules in use (MIT)
```

The published copy lives in `../../public/projects/game-concept/` (generated by `tools/build.mjs`, listed in its `build-manifest.json`).
