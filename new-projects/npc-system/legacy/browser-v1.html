Implementation & demo boundaries

Created September 27, 2026. Original Java quest state machine and compiled Paper 1.21.11 adapter. In Minecraft, an administrator spawns Rowan; right click opens dialogue, and commands accept, offer copper and claim an emerald. Quest state is per player and held in memory.

This browser is a JavaScript simulation of the tested transitions with an original illustration. It is not Minecraft, a live server or an in-game screenshot. “Find fragment” stands in for the native copper inventory prerequisite. The plugin does not persist progress across server restarts.
