# Совместимость и доказательства

Состояние на 27 сентября 2026 года. Один и тот же JAR с Java `--release 16` проверен на пяти точных серверных стендах ниже. Объявленный `api-version: 1.16` не является диапазоном проверенной поддержки. Промежуточные версии Minecraft не считаются проверенными автоматически.

## Компиляция и методика

- Плагин собирается против Spigot API 1.16.5 с Java `--release 16`; API-библиотеки не включаются в плагин.
- Поле `api-version: 1.16` описывает Bukkit API-контракт, не полноту тестирования.
- Отдельные Java-проверки конфигурации/алгоритмов используют прокси объектов; они не являются игровым сервером.
- Каждый серверный прогон использует настоящих сетевых игроков и проверяет 112 утверждений поведения. Проверка графа добавляет 684 утверждения: 14 узлов, 33 реальных варианта и 36 индивидуальных отказов условий, включая синтетические условия. Это проверочные утверждения, не число визуально сыгранных сцен.
- На 26.3 Prismarine-протокол не поддерживается, поэтому сетевых игроков обеспечивают два официальных графических клиента Mojang 26.3. Для остальных стендов использованы сетевые тестовые клиенты.
- Настоящие кадры гавани: `web/assets/game/harbor-overview.png`, `web/assets/game/harbor-ships.png`; официальный vanilla-клиент на Paper 1.21.11, без шейдеров. Художественные изображения лендинга подписаны отдельно.

## Оставшиеся проверки и ограничения

Ранее завершённый отдельный прогон перезапуска: **7 проверок пройдено**. Финальный расширенный прогон перезапуска на 15 утверждений ещё выполняется владельцем выпуска; его результат будет внесён отдельно. Проверяйте эту таблицу перед установкой и используйте Java, требуемую выбранным сервером.

Инвентарь, Vault-провайдер и YAML не делят общую ACID-транзакцию; авария между записями требует ручного разрешения pending-выдачи. Торговля не имеет долговечного журнала аварийного восстановления. Нативные маршруты не ищут обход препятствий. Служебные сообщения пока частично английские. Подробности: [README.md](README.md), [docs/CONFIGURATION.md](docs/CONFIGURATION.md).
