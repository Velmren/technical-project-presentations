# Brand logo sources

Retrieved 2026-09-27. All 18 catalog brands use genuine vector artwork hosted locally; no icon package is added to the application. Simple Icons artwork was extracted from the npm registry tarball for version 16.33.0, with each slug checked against package metadata. Beats uses **Beats by Dre**, not the unrelated Elastic Beats icon.

Only presentation is normalized: navy (#17263c) fills, tightly fitted view boxes, and removal of irrelevant lockup text for Canon. Original path geometry is retained. The Microsoft and iRobot symbols appear beside their names in the component.

## Fallback and accessibility

All current catalog brands are covered. Unknown future brand names render as readable text; they are never assigned a fabricated logo. The component has a brand accessible name and decorative images with empty alt text.
