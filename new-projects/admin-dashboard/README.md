# ORBIT

Операционная панель интернет-магазина на React. Пространство вымышленной компании Northline Objects: около 14 000 заказов и 10 000 клиентов за восемнадцать месяцев, 14 товаров, команда из 14 человек, платежи, задачи и переписка. Все разделы работают на одних и тех же данных.

Разделы: обзор, заказы, клиенты, товары, платежи, аналитика, задачи (доска с перетаскиванием), сообщения и настройки с командой и правами ролей. У каждого действия есть отмена, у каждой записи своя ссылка.

## Запуск

Из `new-projects/admin-dashboard`:

```bash
npm ci
npm run dev -- --port 5188
```

`npm run build` проверяет типы и полноту словарей и собирает проект в `public/projects/admin-dashboard`. `npm run preview -- --port 5190` раздаёт сборку по адресу `http://127.0.0.1:5190/projects/admin-dashboard/`.

## Как устроено

- **Данные.** `src/data/generate.ts` строит пространство детерминированно из одного зерна в Web Worker, поэтому интерфейс не замирает при запуске. Изменения пользователя сохраняются в браузере как журнал действий (`src/data/actions.ts`): при загрузке журнал применяется к тому же исходному набору. Так работает и «Отменить» у уведомлений.
- **Переводы.** Словари на ключах: `src/i18n/en.ts` задаёт структуру, `ru.ts` обязан ей соответствовать. `npm run check:i18n` проверяет плюральные формы и подстановки.
- **Движение.** Токены длительностей, кривых и пружин в `src/motion/tokens.ts`. Уменьшение движения берётся из системы и из настройки пространства.
- **Маршруты.** Hash-маршруты вида `#/orders/NL-23786?view=toPack`: фильтры и открытая запись сохраняются в ссылке. Раздел с несохранёнными изменениями спрашивает перед уходом (`blockNavigation` в `src/app/router.ts`). Все разделы, кроме «Обзора», грузятся отдельными частями и подгружаются заранее, пока браузер свободен.
- **Права.** Матрица возможностей ролей в `src/data/permissions.ts`. Владелец может открыть пространство от имени любой роли («Смотреть как» в настройках): разделы и кнопки ведут себя так, как у этой роли.

## Ограничения

Сервера нет. Оплаты, возвраты и ответы клиентам меняют только локальные записи в этом браузере. Отчётная дата зафиксирована на 29 сентября 2026 года, 14:32 по Дублину; дальше время идёт от этой точки, пока вкладка открыта.

## Проверка

- `npm run build`: типы, словари, сборка.
- `npm run record -- <адрес> <папка> [overview|sections|work|mobile|all]`: запись реального движения интерфейса в webm (Playwright): обзор и заказы, клиенты с товарами, платежами и аналитикой, задачи с сообщениями и настройками, телефон.
