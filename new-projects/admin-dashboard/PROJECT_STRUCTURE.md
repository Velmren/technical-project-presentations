# Структура ORBIT

```
admin-dashboard/
├── index.html              точка входа Vite, метаданные страницы
├── package.json            зависимости и команды: dev, build, preview, check:i18n, record
├── vite.config.js          сборка в ../../public/projects/admin-dashboard, статика из static/
├── tsconfig.json           настройки TypeScript
├── README.md               что это, как запустить и как устроено
├── PROJECT_STRUCTURE.md    эта карта
├── scripts/
│   ├── serve.mjs           раздача собранного проекта на порту 5190
│   ├── check-i18n.mjs      сверка словарей RU/EN и плюральных форм
│   └── record-motion.cjs   запись движения интерфейса в webm через Playwright
├── static/                 файлы, которые копируются в сборку как есть
│   ├── assets/             тексты лицензии OFL для шрифтов Inter и Caveat, попадают в assets/ сборки рядом со шрифтами
│   ├── brand/              логотип и знак в SVG: версии для тёмного и светлого фона
│   ├── favicon.svg, favicon.ico   значок вкладки: SVG меняет цвет по теме браузера, ICO для клиентов без SVG
│   ├── apple-touch-icon.png, icon-*.png, site.webmanifest   иконки приложения и их описание
│   ├── og.png              картинка для ссылок в соцсетях и мессенджерах, 1200x630
│   ├── products/           фото товаров, 112 и 512 px, WebP
│   ├── workspace-preview*.webp  снимки «Обзора» для ноутбука на главной странице
│   ├── thumbnail.png       карточка проекта для главной страницы портфолио
│   └── interface.json      описание проекта для главной страницы портфолио
└── src/
    ├── main.tsx            подключение стилей и провайдеров, запуск React
    ├── app/                оболочка: логотип, маршруты с защитой несохранённых изменений, боковое меню,
    │                       верхняя панель, меню команд, уведомления, меню профиля, горячие клавиши,
    │                       права ролей и режим «смотреть как», загрузка разделов по требованию
    ├── features/
    │   ├── landing/        презентационная страница ORBIT
    │   ├── overview/       раздел «Обзор»: показатели, графики, последние заказы, лента событий
    │   ├── orders/         раздел «Заказы»: очереди, фильтры, таблица, массовые действия, карточка заказа
    │   ├── customers/      раздел «Клиенты»: сегменты, таблица, карточка клиента с историей и блокировкой
    │   ├── products/       раздел «Товары»: сетка и таблица, остатки, карточка товара с правкой и дозаказом
    │   ├── payments/       раздел «Платежи»: сводка, отказы и переводы, карточка платежа, возвраты
    │   ├── analytics/      раздел «Аналитика»: выручка, каналы, товары, страны, тепловая карта по часам
    │   ├── tasks/          раздел «Задачи»: доска с перетаскиванием, список, создание и карточка задачи
    │   ├── messages/       раздел «Сообщения»: входящие, переписка с карточкой заказа, быстрые ответы
    │   └── settings/       раздел «Настройки»: профиль, магазин, уведомления, команда и права ролей, интерфейс
    ├── data/               модель данных: генерация пространства, действия и журнал изменений,
    │                       индексы, метрики, очереди «требует внимания», часы пространства
    ├── i18n/               словари en/ru на ключах, форматирование чисел, денег и дат
    ├── motion/             токены движения, режим уменьшенного движения, счётчик чисел
    ├── charts/             график с областью, спарклайн, кольцевая диаграмма, полосы, тепловая карта,
    │                       математика кривых
    ├── ui/                 общие компоненты: кнопки, значки, панели, выпадающие меню, таблица данных,
    │                       панель массовых действий, боковая панель и диалоги, уведомления, переключатели
    ├── lib/                мелкие утилиты: поиск без учёта регистра, выгрузка CSV
    └── styles/             токены дизайна, базовые стили, стили компонентов, оболочки и списков
```
